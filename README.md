# conduit

macOS 文件传输工作台：左侧浏览本地，右侧浏览 SSH 服务器，勾选或拖动文件即可上传、拉取。常用的两侧位置可以保存为书签，重复的传输可以保存为方案。

## 开始使用

开发环境使用 Node.js 24 或更新版本，安装依赖后启动：

```bash
npm ci
npm start
```

本地需要 `ssh` 和 `rsync`，服务器需要 `sshd` 和 `rsync`。从 Finder / Dock 启动时，应用会从登录 shell 补回 `PATH`、`SSH_AUTH_SOCK`，以使用 Homebrew rsync 或 SSH agent。

1. 在工作台点「管理服务器」，添加 SSH 别名或 `user@host`，按需填写端口、标签和认证方式。
2. 在两侧打开目录。点击文件夹进入，点击 `..` 返回；路径栏可以逐级跳转，也可以点铅笔输入路径后回车。
3. 勾选文件或文件夹，点击上传 / 拉取，或拖到另一侧。目标是接收侧**当前目录**，拖动是复制，不会移动源文件。
4. 在底部任务中心查看进度、取消任务、重试未完成项。成功任务自动折叠，点击「任务中心」或「已完成」可查看。

首次连接 SSH 主机前，请在终端连接一次并确认主机指纹。首次访问局域网时，允许 macOS「本地网络」权限；拒绝后可到「系统设置 → 隐私与安全性 → 本地网络」重新允许，然后重启应用。

顶部的太阳 / 月亮按钮可以切换日间、夜间模式，选择会保存，重启后恢复；系统文件选择框和确认框也会跟随。

启动窗口会按当前屏幕的可用区域居中设置尺寸，避开菜单栏和 Dock，初始高度最高 1100；两侧文件列表使用剩余空间独立滚动。

## 文件浏览与传输

- 两侧列表支持名称、大小、修改时间排序，文件夹始终在前。目录大小显示 `—`，不递归扫描。
- 可以多选文件、目录；进入另一个目录或切换服务器会清空选择。每层最多展示 2000 项。
- 中间分隔线可拖动调整宽度，也支持聚焦后用左右方向键调整。
- 同名目标按 rsync 规则更新或覆盖，目标中的额外文件不会自动删除。工作台上传目录会保留目录名，拉取保存为 `本地目录/原名称`。
- 传输完成仅刷新接收侧，源侧保留滚动位置。普通刷新保留已有列表，避免闪空。
- 删除前会显示确认：本地移到废纸篓；远端永久删除，目录包含其内容。删除与传输共享调度器，冲突路径会等待，不会边删边写。

传输不是原子发布，线上程序可能读到正在写入的文件。发布生产服务时，应传到新的版本目录，再通过自己的部署流程切换版本。

## 书签、常用目录与方案

**书签**记住「本地目录 ↔ 服务器 / 远端目录」，点击一次同时切换两侧位置。

**常用目录**在各侧列表下方，点击切换该侧目录，星标收藏或取消收藏当前目录。远端常用目录随服务器配置保存；本地常用目录随工作台设置保存。

**方案**保存固定的传输内容。方案页合并展示上传、拉取，可直接执行、编辑原方案或删除。上传方案可配置多个服务器 / 目录目标。

当前上传方案只能保存一个来源文件或目录；工作台可以多文件上传，但还不能把多文件批次整体保存为一个方案。删除服务器不会删除引用它的方案；执行失效方案时会提示编辑目标。

操作错误使用右上角可关闭的浮层提示，不占用底部空间；表单校验和目录读取错误保留在对应位置。

## 多任务与活动记录

不同方案、工作台上传和拉取可以同时提交，共享默认 4 路传输并发；同一方案运行时不能重复启动。相同主机、端口和相同或上下级路径的写入会排队；拉取到冲突的本地目录、上传期间删除本地源文件也会排队。非冲突操作继续执行。

冲突判断会识别普通 SSH `HostName` / `Port` 别名，但不能完全识别远端符号链接、动态 `Include` / `Match` 配置或不同 DNS 名称指向同一主机的情况。

活动记录默认单行省略，点击展开完整内容、命令和输出，支持复制。保留最近 1000 条，单条详情最多 20000 字符。顶部「完整日志文件」可定位日志，超过 5 MB 轮转为 `conduit.log.1`。

关闭窗口在 macOS 上不会立即退出后台服务；退出应用会结束服务。任务不会跨应用重启恢复，刷新界面可以恢复当前服务中的任务。

## 数据、备份与恢复

顶部「配置文件」可以定位文件、导出 / 导入备份，或从自动备份修复损坏配置。

| 数据                                 | 正式版位置                        |
| ------------------------------------ | --------------------------------- |
| 服务器、远端常用目录、服务器顺序     | `~/.config/conduit/servers.json`  |
| 上传 / 拉取方案                      | `~/.config/conduit/presets.json`  |
| 书签、本地常用目录、工作台位置与页面 | `~/.config/conduit/settings.json` |
| 日志与活动记录                       | `~/Library/Logs/conduit/`         |
| 密码                                 | macOS 钥匙串，服务名 `conduit`    |

写入使用临时文件加原子替换，并保留上一次有效内容为 `.bak`。损坏或格式异常时会报错，原文件不会被当成空列表覆盖。「修复自动备份」只修复无法读取的文件；修复和导入前的原文件会保留为 `.before-restore-*`，以便回退。

导出包含服务器、方案、书签和设置，**不包含 SSH 私钥和钥匙串密码**。换电脑恢复后，密码认证可能需要重新填写；SSH 密钥和 `~/.ssh/config` 需自行迁移。恢复前应完成或取消传输、等待文件操作结束。

旧版浏览器存储中的书签和本地常用目录会在首次读取时迁移，旧数据不会删除。若旧版曾因端口占用而换端口启动，可能需要在原访问地址启动一次以读取那一份旧存储；迁移到 JSON 后不再依赖端口。

## 配置与认证

SSH 密钥认证使用 `ssh-agent`、`~/.ssh/config`，应用不读取私钥内容。密码认证仅支持 macOS 钥匙串，通过 `SSH_ASKPASS` 提供给 SSH；不自动接受未知主机指纹。

服务器配置示例：

```json
[
  {
    "id": "server-id",
    "name": "web1",
    "host": "prod-web1",
    "port": 22,
    "dirs": ["/var/www/releases"],
    "tags": ["生产"],
    "auth": "key"
  }
]
```

数组顺序即服务器选择框的展示顺序，可在管理服务器抽屉中拖动或上移、下移。手动修改配置前请退出应用并备份。

| 环境变量                   | 默认值 / 作用                                 |
| -------------------------- | --------------------------------------------- |
| `CONDUIT_DATA_DIR`         | `~/.config/conduit`，三个 JSON 文件的默认目录 |
| `CONDUIT_CONFIG`           | 覆盖服务器配置文件路径                        |
| `CONDUIT_PRESETS`          | 覆盖方案文件路径                              |
| `CONDUIT_SETTINGS`         | 覆盖工作台设置文件路径                        |
| `CONDUIT_LOG_DIR`          | 覆盖日志和活动记录目录                        |
| `CONDUIT_KEYCHAIN_SERVICE` | 钥匙串服务名，默认 `conduit`                  |
| `CONDUIT_PORT`             | 正式版 `4322`，开发版 `4323`                  |
| `CONDUIT_TIMEOUT`          | SSH 短命令超时秒数，默认 `30`                 |
| `CONDUIT_PARALLEL`         | 全局并发数，默认 `4`，范围 `1–16`             |

服务只监听 `127.0.0.1`，不提供远程访问认证，不应改为 `0.0.0.0`。

## 开发与发布

```bash
npm run dev        # 前端热更新，独立开发数据、日志、钥匙串命名空间
npm run check      # 类型、Lint、格式、服务端测试、界面测试、前端构建
npm run dist       # 生成 release/ 下的 macOS .app
npm run dist:dmg   # 生成 DMG
```

开发版默认使用 `~/.config/conduit-dev`、`~/Library/Logs/conduit-dev` 和钥匙串服务 `conduit-dev`，不会自动复制正式数据。显式设置上述路径变量会覆盖隔离目录，使用前请确认。
