# 发布检查

1. 更新 `package.json` 版本并保持锁文件同步，运行 `npm run check`。
2. 运行 `npm run dist`，检查 `release/` 中 `.app` 包含 `electron/`、`server/`、`bin/` 和 `web/dist/`。
3. 从 Finder 启动打包应用，验证窗口、预加载桥接、配置菜单、备份和目录浏览，不只验证开发环境。
4. 用临时文件和测试主机执行 [测试说明](TESTING.md) 中的浏览、传输、删除、取消、恢复和隔离检查。
5. 验证 SSH agent、密码认证、首次主机指纹、局域网权限、关闭窗口后重新打开与退出应用。
6. 运行 `npm run dist:dmg`，安装后再执行一次简短回归。

应用使用 ad-hoc 签名，自用分发不等同于 Apple 公证。首次打开可能需要 Finder 右键「打开」，系统行为以目标 macOS 的实际提示为准。

保留 `build/after-pack.cjs` 的 Mach-O UUID 修正钩子，用于稳定本地网络授权标识。调整打包器、Electron 或钩子后，需要实机复查局域网访问权限，不能仅凭打包成功判断。

发布记录应包含版本、主要功能、配置迁移 / 兼容性、自动检查结果和实际完成的手动验证。不能将模拟测试通过写成真实 SSH、废纸篓或 DMG 安装验证通过。

备份不含私钥和密码；不要将自己的 JSON 配置、日志、SSH 文件或测试主机信息打入安装包。恢复配置应在传输和删除均结束后进行。
