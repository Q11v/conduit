# 测试说明

## 自动检查

```bash
npm run check
```

也可分别运行：

| 命令                   | 内容                                                              |
| ---------------------- | ----------------------------------------------------------------- |
| `npm run typecheck`    | TypeScript 类型检查                                               |
| `npm run lint`         | JavaScript / TypeScript、React Hooks 静态检查                     |
| `npm run format:check` | Prettier 格式检查                                                 |
| `npm test`             | Node 测试：调度、互斥、任务、删除、配置备份、迁移、恢复和数据隔离 |
| `npm run test:ui`      | React + Happy DOM 界面交互回归                                    |
| `npm run build`        | Vite 生产前端构建                                                 |

测试使用临时目录、模拟 SSH / rsync 和原生桥接；HTTP 适配器测试会启动一个临时的 `127.0.0.1` 服务，不连接真实 SSH 主机，也不删除现有用户文件。受限沙箱中，HTTP 启动测试需要允许本地端口监听。界面测试在进程内模拟 DOM，不打开浏览器。生成的临时构建文件会清理。

界面测试覆盖：目录名称首次单击和连续进入、拖拽与点击区分、接收侧刷新保留已有列表和滚动位置、取消删除不调用废纸篓、书签切换两侧、拖拽提交目标和已完成任务折叠。

Happy DOM 不能验证 Electron 原生拖拽、macOS 废纸篓、真实布局尺寸、系统权限和 SSH 实际行为，这些仍需手动回归。

## 手动回归

使用专门的临时本地目录和测试服务器目录，不使用生产路径。

- 首次启动：无配置、空服务器、空方案、空目录均能正常操作；错误有明确反馈。
- 浏览：文件名、文件夹图标和 `..` 点击正确；长路径、长文件名、滚动条和面板调整不会破坏两侧对齐。
- 传输：单文件、多文件、目录上传 / 拉取正确；同名更新不会误删目标额外文件。
- 拖拽：已选和未选条目、跨面板、外部本地文件拖入；不应因轻微移动丢失普通单击。
- 进度：取消一个任务不影响其他任务；失败可重试；成功默认折叠；源侧滚动位置保留。
- 删除：取消确认无副作用；本地进入废纸篓；远端仅删除选中项；冲突的传输与删除按顺序执行。
- 书签：一键切换两侧；本地和远端常用目录可收藏、取消；重启后仍存在。
- 方案：直接编辑不另建条目；多服务器执行；失效服务器给出错误。
- 配置：导出后恢复；损坏 JSON 不覆盖原文件；自动修复保留原文件；密码需要重新提供时提示清楚。
- 隔离：同时启动开发版和正式版，在开发版创建服务器 / 书签，正式版数据应保持不变。

发布前的安装包检查另见 [RELEASE.md](RELEASE.md)。
